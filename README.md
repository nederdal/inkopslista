# Inköpslistan 🛒

En enkel och glad inköpslista som körs helt i webbläsaren.

## Vad appen gör

- Lägg till varor i listan.
- Bocka av varor när de ligger i korgen. Avbockade varor flyttas längst ner.
- Ta bort enskilda varor med ✕-knappen.
- Rensa alla avbockade varor på en gång med knappen **Rensa avbockade**.
- Listan sparas i webbläsarens `localStorage`, så den finns kvar när du laddar om sidan.

Appen fungerar lika bra på mobil som på dator.

## Kom igång

Ingen installation behövs. Öppna `index.html` i en webbläsare.

Appen består bara av HTML, CSS och JavaScript och använder relativa sökvägar, så den kan publiceras direkt med GitHub Pages.

## Filer

- `index.html`: startsidan
- `style.css`: utseendet
- `app.js`: logiken och sparningen
- `favicon.svg`: ikonen
